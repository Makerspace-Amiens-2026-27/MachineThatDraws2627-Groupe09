# Abdelnour
# semaine du 25/09/2026

### Présentation du besoin

Notre projet répond à un besoin identifié dans le domaine de **MachineThatDraws**. Actuellement, **je fais face quelques contraintes**, ce qui entraîne **la mauvaises gestion du projet**.

L’objectif de ce projet est donc de **fabriquer une machine fonctionnelle capable de dessiner**, afin de répondre aux attentes des **utilisateurs**.

Ce projet permettra notamment de :

* améliorer **l'état général de la machine à étudier** ;
* faciliter **à dessiner des images** ;
* réduire **la mauvaises gestion du temps** ;
* apporter une solution adaptée aux besoins des utilisateurs.

Ainsi, le besoin principal est de **réaliser une machine capable de répondre à nos besoins**.
